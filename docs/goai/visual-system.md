# LIVE IN HDU Agent visual system

- Canvas: 13.333 × 7.5 inches, 16:9.
- Background: #090B12 graphite; secondary panel #121827.
- Primary text: #F7F2E8 warm white; muted text #9AA7B8.
- Action coral: #FF6B57; execution cyan: #2ED3FF; validation green: #43E6A0; risk amber: #FFC857.
- Display font: Aptos Display Semibold; body font: Microsoft YaHei UI.
- Title: 30–36 pt; hero statement: 40–54 pt; body: 17–22 pt; source note: 9–11 pt.
- Safe margin: 0.55 inch; 12-column grid; 0.18-inch gutters.
- Badges: existing = green outline; prototype = cyan fill; roadmap = amber outline.
- No page contains more than 42 Chinese characters outside sources, badges, and UI screenshots.
- No decorative chart is allowed without data; use process, before/after, state, or interface visuals.

## Evidence treatment

- `现有证据` appears as a green-outline badge and must cite a demonstrable platform source.
- `初赛原型` appears as a cyan-fill badge and may show only the persisted GOAI task evidence.
- `复赛路线` appears as an amber-outline badge and must never be visually indistinguishable from a completed integration.
- A completed task frame must retain `537 字失败 → 自动修订 → 492 字通过` and `等待用户确认` verbatim.
