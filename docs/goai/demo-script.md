## Narration

大学生从来不缺信息。真正困难的，是把散落的规则、材料和截止日期，推进成一个可提交的结果。

在 LIVE IN HDU Agent 里，用户只需要说一句：我想参加 GOAI，帮我把初赛准备好。

系统不会返回一段长建议。它创建任务、读取规则、拆解步骤，并在执行前请求授权。

随后，Agent 调用规则、知识、材料、校验和清单工具，把目标变成真实产物。

第一次简介有五百三十七字，校验失败。Agent 自动修订，再次验证，四百九十二字，通过。

文件可以下载，来源可以追溯，任务刷新后仍然存在。涉及官网提交时，系统停在确认门前。

这只是第一条闭环。下一步，它将走向科研、奖学金、升学和实习。

LIVE IN HDU Agent：一句话，把大学生成长目标推进到可提交。
