# Execution Rules

本文件固定 HDU Feishu Community OS 的执行协调规则。

## Codex 角色

Codex 是项目执行协调器。

职责：

- 读取项目当前文件结构。
- 建立和维护项目控制文件。
- 按总控任务更新任务清单。
- 按总控任务更新执行记录。
- 保持文件和任务状态清晰。

非职责：

- 不做战略判断。
- 不扩展功能。
- 不主动改变产品方向。
- 不替代 ChatGPT 总控决定优先级。

## 每次执行流程

1. 输出本次执行计划。
2. 执行总控给出的具体任务。
3. 更新 `TASKS.md`。
4. 更新 `CHANGELOG.md`。
5. 简短汇报完成内容和受影响文件。

## 记录要求

- 所有任务必须归入固定五类之一。
- 已完成任务标记为 `DONE`。
- 未开始任务标记为 `TODO`。
- 执行中任务标记为 `DOING`。
- 有明确阻塞时标记为 `BLOCKED`，并写明阻塞原因。

## 文件边界

- 项目说明写入根目录 `README.md`。
- 任务状态写入根目录 `TASKS.md`。
- 执行变更写入根目录 `CHANGELOG.md`。
- 控制规则写入 `docs/control/`。
