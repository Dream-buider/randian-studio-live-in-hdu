# Task Categories

所有任务必须归入以下五类之一。

## Feishu结构

用于记录飞书知识库、页面树、目录、文档节点、权限入口等结构性工作。

示例：

- 创建知识库
- 创建一级目录
- 创建二级目录
- 调整页面层级
- 记录页面链接

## 内容模板

用于记录内容页格式、文章模板、字段规范和内容生产格式。

示例：

- 统一文章模板
- 建立资料来源字段
- 建立可靠等级字段
- 建立更新时间字段

## AI检索

用于记录飞书知识问答、搜索命中、索引同步、问答可用性检查等工作。

示例：

- 检查知识问答入口
- 记录问答命中情况
- 整理检索关键词
- 记录索引同步状态

## 运营管理

用于记录任务管理、投稿纠错、贡献者、负责人、更新节奏和执行控制。

示例：

- 建立控制文档
- 建立投稿记录
- 建立纠错记录
- 建立负责人记录
- 更新任务状态

## 产品UI

用于记录用户入口、首页导航、页面呈现、路径组织和视觉呈现相关任务。

示例：

- 首页导航结构
- 热门入口布局
- 投稿入口展示
- 页面底部信息区
- 用户访问路径记录
