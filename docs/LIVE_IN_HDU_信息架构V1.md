## 2. 页面层级规范

| 层级 | 作用 | 数量限制 | 示例 |
| --- | --- | --- | --- |
| 一级目录 | 学生阶段或核心问题域 | 最多 8 个 | 新生入学、学业与课程、校园生活 |
| 二级目录 | 具体功能问题 | 每个一级目录最多 10 个 | GPA攻略、转专业、快递、外卖 |
| 三级页面 | 单个可回答知识页 | 按需新增 | 阳光长跑怎么跑、报到当天流程、程设历年卷 |

## 5. 命名规范

| 类型 | 格式 | 示例 |
| --- | --- | --- |
| 一级目录 | 名词短语，不超过 6 个汉字 | 新生入学、校园生活 |
| 二级目录 | 学生会搜索的问题词，不加“库/中心/文档” | GPA攻略、快递、转专业 |
| 三级页面 | 具体问题句或具体对象名 | 阳光长跑怎么跑、程设历年卷 |
| 课程页 | 课程名 + 事项 | 高数复习、程设历年卷 |
| 政策页 | 事项 + 年份/届别 | 2026届保研时间线 |
| 实验室页 | 实验室名 + 信息类型 | 智能信息处理实验室介绍 |
| 投稿页 | 投稿 + 内容类型 | 投稿课程经验 |

禁止词：

- 资源库
- 数据库
- 文档中心
- 资料中心
- 综合入口
- 杂项
- 其他

## 6. 导航规则

| 规则 | 执行方式 |
| --- | --- |
| 学生先选场景 | 一级目录必须是阶段或问题域 |
| 学生再选任务 | 二级目录必须是具体功能问题 |
| AI 先取标题 | 页面标题必须包含可检索关键词 |
| 每页只解决一个问题 | 避免“大全式长文” |
| 不建四级目录 | 需要更细时改用页内标题或多维表格 |
| 高频问题前置 | 新生、课程、选课、生活入口靠前 |
| 政策类标来源 | GPA、转专业、保研、考试必须有来源和复核日期 |
| 经验类标等级 | 单人经验默认 C，多人验证后可升 B |
| 投稿不直接入库 | 投稿先进入共建与反馈，再审核发布 |
| Bot 检索用同名标签 | 页面标题、一级目录、二级目录同步进入 metadata |

## 7. 飞书实际创建方案

### 7.1 现有一级节点处理

| 原节点 | 处理后 |
| --- | --- |
| 首页 | 开始使用 |
| LIVE IN HDU 首页 | 移动到“开始使用”下，改名为“关于 LIVE IN HDU” |
| 新生生存指南 | 新生入学 |
| 学业资料库 | 学业与课程 |
| 选课与培养 | 选课与学籍 |
| 成长发展 | 实验室与科研 |
| 校园生活 | 校园生活 |
| 知识问答与 FAQ | 发展与就业 |
| 共建社区 | 共建与反馈 |

### 7.2 执行顺序

1. 重命名一级目录。
2. 将重复首页移动到“开始使用”下。
3. 按新版二级目录重命名现有二级页面。
4. 为缺失二级目录新建页面。
5. 每个一级目录二级页面不超过 10 个。
6. 不建立四级目录。
7. 后续具体内容统一作为三级页面或页面内表格。

### 7.3 RAG metadata

| 字段 | 值 |
| --- | --- |
| `level_1` | 一级目录名 |
| `level_2` | 二级目录名 |
| `level_3` | 三级页面名，可为空 |
| `student_intent` | 页面解决的问题 |
| `audience` | 新生/本科生/保研/考研/就业等 |
| `source_type` | 官方/经验/投稿/多维表格 |
| `reliability` | A/B/C |
| `review_status` | draft/reviewed/published/archived |
| `last_reviewed_at` | 最后复核日期 |
