# 新生指北信号站设计

## 目标

保留现有问题界面、问答数据、提问流程和路由，仅重新设计 `/guide`：将《杭电新生指北》的四个栏目呈现为沿纵向路线伫立的四座“校园信号站”。

## 用户看到的体验

1. 顶部显示“校园信号已接通”，说明这里是一条从开学准备通向校园生活的路线。
2. 四个栏目按现有顺序排列为站点 `01` 至 `04`，由一条竖向信号线连接。
3. 每个站点保留原有栏目标题、摘要、主题标签和对应飞书链接。
4. 外链按钮改为“接收「栏目名」完整信号”，仍在新窗口安全打开。
5. 页面使用一套完整但轻量的 CSS 动效节奏：顶部信号接通、纵向线路点亮、四座站点依次伫立、接收按钮反馈；系统开启“减少动态效果”时直接显示最终静态构图。

## 视觉方向

- 主色继续使用杭电蓝，青色只作为信号状态提示。
- 背景采用浅蓝灰底和极淡的信号波纹，不引入深色玻璃卡片。
- 站点本体是稳定、竖直的白色信息面板；圆形信号标识压在线路上。
- 顶部增加一枚抽象“信号接收器”，通过同心波纹和状态灯建立第一视觉焦点，不增加图片或 WebGL。
- 线路的点亮只播放一次，站点按阅读顺序错峰就位；悬停、按压和键盘焦点均提供明确反馈。
- 保留社区整理、非官方发布及更新时间说明，不能削弱内容边界。

## 保护范围

- 不修改 `QuestionDeckView.vue`、`QuestionCard.vue`、`QuestionCatalog.vue` 或 `AskSheet.vue`。
- 不修改 `router.ts`、`api.ts`、Mock 数据、后端、Admin、依赖或构建配置。
- 不修改 `FRESHMAN_GUIDE_SECTIONS` 的内容和链接。
- 不提交、不推送、不创建 PR，除非用户另行确认。

## 修改范围

- `apps/freshman-mvp/web/views/GuideView.vue`
- `apps/freshman-mvp/web/styles/tokens.css`
- `apps/freshman-mvp/test/web/guide-view.test.ts`

## 验收标准

- 四个栏目以有顺序语义的信号站路线呈现。
- 标题、摘要、全部主题和外链无丢失。
- 返回问答链接、社区免责声明和更新时间仍存在。
- 触控目标不小于 44px，键盘焦点可见。
- `prefers-reduced-motion` 下不依赖动画显示内容。
- 动画仅改变 `transform` 和 `opacity`，不引入持续滚动监听或新增运行时依赖。
- 现有测试、正式构建和公开试用构建继续通过。
