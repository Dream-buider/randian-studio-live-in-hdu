## 建议备案填写口径

以下内容用于腾讯云备案初审，不替代页面实时要求；如腾讯云审核人员提出修改，以审核意见为准。

- 备案类型：首次备案（若主体此前无备案）；个人备案
- 网站域名：`liveinhdu.cn`
- 推荐网站名称：`余晖校园生活笔记`
- 备选网站名称：`余晖入学生活笔记`
- 网站服务内容：优先选择页面中与“其他 / 生活服务 / 个人网站”最接近且符合实际的选项
- 网站用途说明：

  `个人整理并分享大学新生入学准备和校园生活经验，提供常见问题查询及寝室信息匹配工具，不提供新闻、教育培训、论坛或经营性服务。`

## 命名与内容边界

- 不使用“杭州电子科技大学官网”“杭电官网”等可能造成官方机构误解的名称。
- 个人备案网站名称不使用“燃点工作室”“公司”“协会”“中心”等组织化名称。
- 不把“飞书社区”作为备案网站名称，也不将网站申报为论坛或新闻平台。
- 不承诺招生、录取、学籍、缴费等官方服务。
- 网站页脚上线前补充真实备案号；备案未通过时不伪造备案号。
- 网站名称如被初审退回，仅修改备案名称和页面标题，不变更域名、数据库或功能数据。

## 预计需要本人提供的材料

- 域名实名主体本人的身份证件及有效期信息。
- 本人常用手机号、电子邮箱和通信地址。
- 腾讯云备案小程序的人脸核验或实人核验。
- 备案短信核验验证码。
- 腾讯云页面要求的服务器备案资源或备案授权码；当前服务器在同一腾讯云账号时优先直接选择实例。

上述敏感资料只填写到腾讯云备案页面，不写入代码、Git、项目文档、聊天记录或服务器环境变量。

## 提交前门禁

1. 域名状态为正常，实名认证已通过。
2. 域名实名主体与备案主体一致。
3. 服务器剩余有效期满足腾讯云备案要求。
4. 备案网站名称与实际页面标题能够保持一致。
5. 提交前由域名所有者本人核对所有身份、联系方式和网站用途信息。

## 备案通过后的执行顺序

1. 添加根域名 `@` 与 `www` 的 A 记录，解析到 `124.222.171.40`。
2. 等待公共 DNS 生效并验证两个主机名均只指向目标服务器。
3. 安装 Nginx 域名配置，保留 `/api/admin` 与 `/api/reviews` 的公网拒绝规则。
4. 申请并部署免费 TLS 证书，强制 HTTP 跳转 HTTPS。
5. 运行 `npm run verify:roommates -- --base-url https://liveinhdu.cn`。
6. 备份数据库与环境文件，记录 SHA256 和绝对路径。
7. 仅在全部门禁通过后设置 `ROOMMATE_MATCHING_ENABLED=true` 并重启服务。
8. 使用手机完成客户端、寝室匹配、管理端 SSH 通道和隐私边界验收。
